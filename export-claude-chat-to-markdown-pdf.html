How to export a Claude chat to Markdown or PDF

claude.ai makes it easy to copy a reply but gives you few ways to export a full conversation. Here is what works today.

Export a Claude conversation

  1. Copy a reply. Hover over a Claude reply and click the copy icon. Paste into a Markdown file; formatting such as headings and code fences generally carries over.
  2. Save the chat as a PDF. Open the conversation, press Ctrl+P (Cmd+P on Mac) and choose Save as PDF. Check long code blocks, which can split across pages.
  3. Use the share option if you only need a link. Claude can create a link to a conversation. Anyone with the link can read it, so use it only for chats you are happy to share.
  4. Request your account data. Open Settings and look for the Privacy section, where an Export data option emails you a download link. The result covers your account rather than one chosen chat. The exact menu names and format are described by third-party guides, so confirm them in your own settings.

Notes on Claude Projects

If a chat lives in a Project, the project's knowledge files are not part of the chat text, so a copied or printed chat will not include them. Export those files from the project itself.
