Move your ChatGPT history to Claude.

Claude can import your preferences and memory from ChatGPT, but not your old conversations. This is how to carry the conversations over, so a Claude Project can answer "what did we decide about that?"

The steps

  1. Export your data from ChatGPT. Settings, Data controls, Export data. ChatGPT emails you a link to a zip. The zip holds conversations.json, every chat you have not deleted, plus a chat.html copy.
  2. Open the zip in the ThreadKeep export viewer. Drop it on the page. It is read in your browser and not uploaded. You can search it and read any chat for free.
  3. Choose what Claude should know. You probably do not want all 2,000 chats. Search for a topic, filter by date, or tick the ones that matter: projects you are still working on, decisions, code you reuse.
  4. Press Move to Claude. The tool builds a zip of Markdown files, newest chats first, cut to a size you pick. It also writes an index of what is inside and a short instructions text for the Project. This step needs a ThreadKeep Pro license.
  5. Add the files to a Claude Project. In Claude, create a Project, add the files from the upload-these folder as project knowledge, and paste the text from project-instructions.txt into the Project's instructions. The zip includes these steps as README-add-to-claude.md.

What Anthropic's import does and does not cover

Anthropic's own memory import works by having you ask ChatGPT to summarize what it remembers about you, then pasting that summary into Claude. The result is a profile of your preferences and context. It does not bring over individual conversations, the code you wrote in them, or the details of past decisions. That is the gap this fills. If you only want Claude to know your preferences, the official import is the shorter route.

Moving conversations also has limits worth knowing. Claude reads project knowledge as text, so images, generated files and ChatGPT's tool output do not come across in a useful form. Long chats are shortened in compact mode. And a Claude Project can only hold so much: Anthropic sets those limits and can change them, so check Claude's help pages if an upload is refused. The tool lets you choose a smaller total size and re-export.

Choosing which chats to move

  • By topic. Search a word or "a quoted phrase", press the checkbox above the list to tick everything found, then move just those.
  • By date. Set From and To to take the last six months, for example.
  • By size. The default limit is about 150,000 tokens, which fits Claude's context window. A larger limit works with project search, where Claude looks up the relevant files instead of reading all of them.

Combined files hold several chats each and are the better default, because Claude limits how many files a chat or project takes. One file per chat keeps titles as file names, which is handy for a small selection.

Questions

Is my ChatGPT data uploaded anywhere?

No. The viewer runs in your browser, and its security policy blocks every connection except the license check. See how to verify this.

Does this work from a Claude or Gemini export too?

The viewer opens Claude, Gemini and Grok exports, and Move to Claude works on any of them. The page is about ChatGPT because that is the move most people ask about.

Is the official memory import enough?

If you want Claude to know your preferences, yes. If you want it to be able to look up what you worked out in a specific old conversation, it will not, because those conversations are not part of memory.

What does it cost?

Reading, searching and exporting single chats are free. Move to Claude and bulk export need ThreadKeep Pro, $59 once or $4.99 a month.
