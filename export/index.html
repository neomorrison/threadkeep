    Where to get the export

    Each service emails or prepares a download. Menu names change, so look for data export or Takeout if a label differs.

    1. ChatGPT: Settings, Data controls, Export data. You get an email with a link to a zip that holds conversations.json and chat.html. Drop the zip as it is.
    2. Claude: Settings, Privacy, Export data. The email links a zip with conversations.json.
    3. Gemini: Google Takeout (takeout.google.com), choose My Activity, then pick only Gemini Apps. Drop the Takeout zip, or the MyActivity.json inside it.
    4. Grok: the data export in your Grok account settings. Grok support is the least tested of the four, because its export format is not documented.

    Your files stay in this tab

    This page reads your export with JavaScript running on your computer, and a web worker does the heavy parsing so big files do not freeze the page. The page's Content-Security-Policy, set in its HTML head, blocks every connection except one: the ThreadKeep license check. That check sends the license key and a device label, only after you unlock Pro. It never carries chat text.

    To verify it yourself, open your browser's developer tools, switch to the Network tab, and drop a file. You should see no requests at all. You can also read the policy with View Source, and the code in this folder is not minified, apart from the zip library.

    Questions

    How do I open conversations.json?

    Drop the ChatGPT export zip, or the conversations.json from inside it, onto the box above. Newer ChatGPT exports can split chats across several files such as conversations-000.json, and the viewer reads them all.

    Which version of a ChatGPT conversation do I see?

    ChatGPT stores a conversation as a tree, because editing a message or regenerating an answer creates a new branch. The viewer follows the branch you were last on, which is what you saw in ChatGPT. Older versions of edited messages are not shown.

    What happens to images and files?

    Images appear as a placeholder with the file name, and attachments are listed by name, size and type. The files inside your zip are not extracted in this version.

    How large a file can it open?

    The conversations file is read as a stream, so a single JSON file of several hundred megabytes works. A zip is loaded into memory first, and browsers cap that at about 2 GB. If a very large zip fails, unzip it and drop conversations.json instead.

    Why are my Gemini chats grouped oddly?

    Google's Takeout lists each prompt and answer as a separate activity with no conversation id. The viewer groups prompts that are close together in time into one session. You can change the gap, or show each prompt alone.
