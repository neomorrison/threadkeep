Your AI chats, in folders.

ChatGPT, Claude, Gemini and Grok each keep your history as one long list. ThreadKeep is a Chrome extension that adds folders, tags and search to the sidebars you already use, and saves any chat as Markdown or PDF.

See pricing Free to use. Pending Chrome Web Store review; the install link goes here once it's live.

Find it again

Press Ctrl Shift K (⌘ on a Mac) and type what you remember: a word from the answer, a function name, budget. Search covers every chat you've opened, on all four sites.

Folders work the same way everywhere: drag a chat in, nest folders, color and pin them. A "Thesis" folder can hold a ChatGPT chat next to a Claude one.

Keep a copy

Export one chat or a whole folder to Markdown, PDF, JSON or plain text. Code keeps its language and indentation, and tables stay tables.

Useful for notes apps, for handing an answer to someone without a share link, or just for keeping it.

It stays on your computer

No account, no sign-up, no analytics. Folders and saved chat text live in your browser's storage; we never see them.

The only thing that leaves your browser is a license key, if you buy Pro, so it can be checked. Read the privacy policy.

Questions

What happens when ChatGPT changes its layout?
ThreadKeep checks the page each time it loads. If something moved, it hides its panel and says a fix is coming instead of breaking the site, and the fix ships as a small data update without waiting for a store review.
Where do I get my license key?
It's emailed right after checkout. Paste it into ThreadKeep's settings under "Enter license key".
Is this made by OpenAI or Anthropic?
No. ThreadKeep is an independent tool made by Neo Morrison LLC.
