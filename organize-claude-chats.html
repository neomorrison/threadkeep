How to organize your Claude chats

claude.ai groups conversations with Projects. This guide covers moving existing chats into a project, tidying up, and what folders add.

Group Claude chats with Projects

  1. Create a project. In claude.ai open Projects and create one for the topic. Add instructions or files if you want Claude to use them in every chat in the project.
  2. Move a chat in. Open the chat's menu and choose the option to add it to a project. Claude's help center says you can also move several chats at once from your chat history page.
  3. Start new chats from the project. Chats begun inside a project belong to it and can use its knowledge.
  4. Archive finished projects. Archiving removes a project from the active list without deleting it.
  5. Find things later. Search past chats on paid plans through Claude's chat search. Searches inside a project stay inside that project.

Things to know

Projects are a workspace, not only a label: project knowledge is available to the chats inside. Context does not carry from one chat to the next unless it is in the project knowledge. There is no nesting of projects, and chat search is limited to paid plans. Plans change, so check Anthropic's help center.
